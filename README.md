# GameVault

GameVault is a full-stack web application for managing and exploring a personal video game collection across platforms.

## Planned Features

- Create an account and manage a personal game collection
- Track physical and digital ownership
- Maintain a wishlist
- Record play status, personal ratings, and notes
- Search, filter, and organize games
- View collection statistics and insights

## Technology Stack

**Backend:** Python, FastAPI, SQLAlchemy  
**Database:** PostgreSQL  
**Frontend:** React, TypeScript, Vite  
**Testing:** pytest  
**Development and deployment:** Git, Docker, GitHub Actions, and AWS (planned)

## Project Structure

- `backend/` — REST API and database integration
- `frontend/` — React web application
- `docs/` — project documentation and design decisions

## Development Status

Currently in the initial planning and project setup phase. Features and technologies will be implemented incrementally.

## Goals

GameVault is a portfolio project focused on full-stack development, relational database design, API development, automated testing, and cloud deployment.
